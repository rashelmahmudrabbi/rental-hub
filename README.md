## Overview

Rental-Hub is a modern and responsive rental marketplace website that allows users to browse rental items, explore categories, and list their own products through a clean and interactive user interface.

The project focuses on delivering a professional frontend experience with responsive layouts, smooth animations, and user-friendly interactions.

---

## Features

* Responsive modern UI design
* Interactive single-page layout
* Browse rental listings
* Category-based rental showcase
* List item form
* Combined Sign In / Sign Up system
* Smooth hover and scroll animations
* Toast notification interactions
* Mobile-friendly design
* Real image integration
